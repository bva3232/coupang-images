# coupang-images

쿠팡 상품등록용 **공개 이미지 호스팅**. 쿠팡은 이미지를 URL로 다운로드하므로,
대표/상세 이미지를 여기에 올리고 그 공개 URL을 상품등록 엑셀에 넣는다.

- 공개 저장소(이미지 접근을 위해 public). 개인정보·비밀값은 올리지 않는다.
- 접근 URL 두 가지(둘 다 공개):
  - GitHub Pages: `https://bva3232.github.io/coupang-images/<경로>`
  - Raw: `https://raw.githubusercontent.com/bva3232/coupang-images/main/<경로>`

## 상품별 폴더
- `chiikawa/` — 치이카와 말랑 무드등
  - `detail.jpg` — 상세페이지(상세이미지URL)
  - `rep_chiikawa.jpg` / `rep_hachiware.jpg` / `rep_usagi.jpg` — 옵션별 대표이미지
